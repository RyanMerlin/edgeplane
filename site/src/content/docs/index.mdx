## What is EdgePlane?

AI agents can write code, run tools, and reason over architecture. What they can't do is **coordinate**.

Without a shared system of record, parallel agents duplicate effort, diverge on state, and collide on artifacts with no resolution path.

EdgePlane is a **control plane for AI agents and human collaborators**. It provides:

- **OIDC Authentication & Governance** — OIDC/PKCE login, role-based access, versioned policy lifecycle, and HMAC-signed approval tokens
- **ACP Sessions & Persistent Agents** — `edgeplaned` manages long-running agent processes over the Agent Communication Protocol; sessions survive crashes and reconnects
- **Multi-Agent Mesh** — structured domains, missions, and tasks with overlap detection; agents coordinate without duplicating work or colliding on artifacts
- **MCP-Native Interface** — standard MCP stdio tools and a real-time WebSocket event bus; works with any MCP-compatible agent
- **Zellij Integration** — first-class Zellij plugin (zrpc) for fleet management directly inside your terminal
