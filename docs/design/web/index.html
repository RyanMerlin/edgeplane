edgeplane Web Design System — v1 Edgeplane Frontend Revamp · 2026

Edgeplane Web — Design Mockups

Complete visual redesign of the edgeplane-tower frontend. Dense, monospace-first, multi-pane operator console. No pills, no glass-morphism, no marketing aesthetics. Built for systems engineers.

What changed from the current frontend: Eliminated all pill-shaped elements (border-radius: 999px everywhere). Removed glass-morphism panels and radial gradient backgrounds. Replaced floating card stacks with horizontal pane layouts. Switched from Space Grotesk to monospace-first typography. Added top status bar and bottom statusbar. Every page now uses the same design system: #0d1117 base, #161b22 surface, #21262d border, semantic color tokens.
