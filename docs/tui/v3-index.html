What Changed vs v2

  • Agents is now first-class — real agent fleet matrix with node topology, not a mission task tree new
  • Missions reflects the actual model — persistent namespaces, Mission → Kluster → Task. Nothing "completes" at the mission level fix
  • Feed has text search + type filters — scales to any number of missions/agents; no chip-per-mission that overflows fix
  • Alerts are inline in Feed — errors and governance events get a left-border accent and background, not a separate tab fix
  • Feed rows open a right split pane — select any event to see full detail without leaving the stream new
  • Approvals tab removed — governance events surface in Feed; policy resolution doesn't block unrelated agents removed
  • Receipts tab removed — task history lives in Missions and agent detail panel removed
  • Raft removed from Config — decommissioned removed
  • Matrix renamed to Missions — "Matrix" connotes agent matrix, which is now the Agents tab fix

Navigation Model

  • Arrow keys navigate within the focused pane
  • Tab cycles focus between panes in the current screen
  • a m f c switch tabs
  • Enter selects / drills in; Esc goes back or closes detail pane
  • / focuses the filter input in Feed
  • n launch new agent (Agents tab)
  • Ctrl+Q quits
