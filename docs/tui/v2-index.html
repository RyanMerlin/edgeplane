What Changed vs v1

  • No more blank landing screen — Matrix is the default view, loads data immediately new
  • Persistent tab bar at top — all screens always visible, no memorizing key bindings new
  • Approval badge count in tab bar — know without switching views new
  • Config screen with sidebar nav — server URL, auth, Infisical, display settings new
  • Breadcrumb status bar — always shows Mission › Kluster › Task context new
  • Feed has filter bar — chips for mission / agent / event type, active filters shown inline fix
  • Approvals show risk level color-coded HIGH/MED/LOW with left border accent fix
  • Task table has Agent + Duration columns — not just status fix
  • Empty states are informative — "no tasks — select a kluster" not just blank fix
  • Secrets screen removed from main nav — moved to Config → Infisical moved
  • Help screen removed — key hints shown inline in status bar at all times removed

Navigation Model

  • Arrow keys navigate within the focused pane
  • Tab cycles focus between panes in the current screen
  • 1–5 or shortcut keys switch tabs: m matrix · f feed · a approvals · q receipts · c config
  • Enter drills down (mission → kluster → task → detail)
  • Esc goes back one level
  • Ctrl+Q quits
